# Host_Computer 二进制帧协议层

该工程当前只提供通用二进制帧收发和解析，不定义任何业务命令、状态或应用动作。

## 帧格式

| 字段 | 长度 | 说明 |
| --- | ---: | --- |
| 帧头 | 2 字节 | 固定为 `AA 55` |
| 地址 | 1 字节 | 默认本机地址 `01`，广播地址 `FF` |
| 命令 | 1 字节 | 由后续应用层定义 |
| 数据长度 | 2 字节 | 小端序，最大 64 字节 |
| 数据 | N 字节 | 由后续应用层定义 |
| CRC16 | 2 字节 | CRC-16/MODBUS，小端序 |

CRC 覆盖地址、命令、长度和数据，不包含帧头与 CRC 本身；初值 `0xFFFF`，多项式 `0xA001`。

## 接收与发送

UART 使用单字节接收中断。协议层只负责组帧、CRC 校验、地址过滤和 4 帧接收队列；调用 `BinaryProtocol_ReadFrame()` 可取出完整帧。无效帧、非本机地址帧和队列满时的新帧会直接丢弃，不产生业务响应。

调用 `BinaryProtocol_SendFrame(address, command, payload, length)` 可发送任意符合该帧格式的数据。
